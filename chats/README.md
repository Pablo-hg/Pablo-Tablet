## Estado actual del desarrollo

- Motor de páginas y widgets con slider, indicadores, rotación automática y activación desde Ajustes.
- Navegación contextual con ocultación automática.
- Gesto horizontal disponible sobre las zonas libres, sin bloquear la interacción dentro de los widgets.
- Notas locales con varias entradas, colores, fijado, archivado, restauración y eliminación.
- Página del reloj ampliada con alarmas y varios temporizadores persistentes.
- Próxima alarma o temporizador en marcha reflejado en el dashboard.
- Primera página del tiempo integrada con datos de demostración y previsiones visuales.
- Preferencias y datos funcionales guardados localmente con migración entre versiones.

## Pendientes registrados

- Dejar para una fase posterior el desarrollo completo del tiempo: API real, gestión de ciudades, ubicación, refresco y estados sin conexión.
- Añadir notificaciones nativas de Android para alarmas, temporizadores y recordatorios.
- Continuar con calendario, galería y salvapantallas según las fases documentadas en estas conversaciones.
